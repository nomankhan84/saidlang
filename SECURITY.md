# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SaidLang, please do not open a public issue. Instead, report it responsibly:

1. Send an email to the project maintainers via GitHub security advisories or repository contact.
2. Include clear steps to reproduce the vulnerability.
3. We will acknowledge receipt within 48 hours and work on a fix promptly.
